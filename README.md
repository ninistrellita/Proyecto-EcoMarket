Este es un proyecto de plataforma web de comercio electrónico (E-commerce)
enfocado en la venta de productos ecológicos, biodegradables y residuo cero (zero waste).
Nuestro objetivo es facilitar el acceso a un estilo de vida más consciente y respetuoso con el medio ambiente.

Descripcion ddel proyecto:
EcoMarket es una solución digital moderna que conecta a consumidores conscientes con
alternativas sustentables para el día a día. La plataforma permite a los usuarios explorar productos
por categorías (hogar, cuidado personal, alimentación, etc.), gestionar un carrito de compras y 
conocer el impacto ambiental positivo de sus elecciones de consumo.

El proyecto fue construido utilizando el siguiente stack tecnológico:

Frontend: HTML5, CSS3 (Sass / Tailwind CSS para estilos)

Fuentes: Google Fonts (un estilo muy natural y limpio)

Control de Versiones: Git y GitHub.
